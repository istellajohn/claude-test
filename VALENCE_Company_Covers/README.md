# VALENCE Company Covers v01

**Purpose:** LinkedIn, Facebook and YouTube company covers for VALENCE, three creative directions (A, B, C) awaiting selection.

## Deliverables
| File | Size | Use |
|---|---|---|
| `05_EXPORTS/social/upload_ready/VALENCE_linkedin_cover_[A-C]_3840x650.jpg` | 3840 x 650 | LinkedIn Page cover |
| `.../VALENCE_facebook_cover_[A-C]_3840x2160.jpg` | 3840 x 2160 | Facebook Page cover |
| `.../VALENCE_youtube_banner_[A-C]_2560x1440.jpg` | 2560 x 1440 | YouTube channel art (2K) |
| `05_EXPORTS/social/final/` (not in git, regenerate) | PNG masters incl. YouTube 3840 x 2160 | lossless masters |

## Working files
Editable HTML/CSS per cover: `04_WORKING/layouts/{A,B,C}/{linkedin,facebook,youtube}.html` plus `layouts/shared/base.css`. Everything is generated by `04_WORKING/source_files/build_covers.py`; edit that or the HTML directly.

## Fonts
Switzer (Fontshare, ITF FFL), DM Mono (Google Fonts, OFL). Details and licences in `ASSET_REGISTER.md`. **Switzer is not in git** (licence forbids redistribution): download from https://www.fontshare.com/fonts/switzer and unzip into `02_BRAND/fonts/Switzer/`.

## Colours
Onyx `#0A0A0A` (10,10,10), Bone `#F3F2EF` (243,242,239), Stone `#A6A39E` (166,163,158), Verve `#E35A2A` (227,90,42), Gold `#C8A24C` (200,162,76), Forest `#223D2E`, Sea `#0B5962`. CMYK not defined by the deck; not needed for screen covers.

## Assets
Logos: `02_BRAND/logos/` (supplied PNG plus traced `svg/`). Photography: NASA/USGS Landsat, originals re-downloadable by nasa_id (see register). Crops used by the layouts: `03_ASSETS/photography/graded/crops/`.

## External dependencies
Python 3.13, `playwright` (Chromium), `pillow`, `numpy`, `potracer`. Chromium path is set in `build_covers.py`.

## Rebuild
```
python3 -I 04_WORKING/source_files/trace_logos.py     # only if logos change
python3 -I 04_WORKING/source_files/grade_images.py    # needs the two originals
python3 -I 04_WORKING/source_files/build_covers.py final
python3 -I 04_WORKING/source_files/make_boards_and_uploads.py
python3 -I 04_WORKING/source_files/build_avatars.py   # profile pictures + board
```

## Editing notes
- **To swap a logo:** replace the SVG in `02_BRAND/logos/svg/` (keep the filename) and rebuild.
- Logo, text and rules are CSS-positioned; no hard-coded raster text anywhere.
- YouTube content must stay in the 773 x 211.5 strip; Facebook content inside y 184 to 896.
- Re-test in each platform's preview before publishing; Meta's spec page is dated.
