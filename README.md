# VALENCE

Landing page for VALENCE (previously Copious Space): perception architecture for brands, founders and ideas whose substance has outgrown its expression.

Static site, no build step. Open `index.html` or serve the folder with any static host.

- `index.html`: page structure and copy (from the 2026 credentials deck)
- `assets/css/style.css`: tokens from the VALENCE Brand Identity System (Onyx, Bone, Stone, Verve, Gold; Forest and Sea for the four charges)
- `assets/js/main.js`: WebGL hero (a split monolith with a seam of light that opens as you scroll), capability stack, orbit and stage interactions
- `assets/vendor/three.min.js`: three.js r149, vendored (MIT, see `three.LICENSE`)

Fonts are Google Fonts stand-ins until the licensed faces are chosen: Archivo Expanded in place of Söhne Breit, Hanken Grotesk in place of Neue Haas Grotesk, and Cormorant Garamond for the signature/contrast role.
